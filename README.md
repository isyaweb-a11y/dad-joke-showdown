An entry for the make.fun bounty **Dad Joke Showdown**
(https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

`main.py` (Python standard library only) writes one dad joke — at most
200 characters — to `/output/entry.txt`:

> I set our Wi-Fi password to 'incorrect', so whenever my kids forget
> it, their phones remind them: 'Your password is incorrect.'

A father sets the family Wi-Fi password to the word "incorrect", so
the router delivers the punchline itself every time a kid forgets it.
